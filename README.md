# Rolls-Royce Black Badge Interactive Experience

A high-fidelity recreation of the mobile Rolls-Royce Black Badge digital experience matching the reference interaction flow.

## 🚀 Quick Start
Double-click `index.html` (or `rolls_royce_experience.html`) to launch the experience in any modern desktop or mobile browser.
No local web server, build step, or internet connection is required—all assets, audio, and video media are fully embedded and self-contained.

## 📁 Package Contents
- `index.html`: Main interactive application (fully standalone with embedded base64 media).
- `rolls_royce_experience.html`: Direct copy for alternative naming compatibility.
- `assets/`: Standalone raw media assets (PNG images, MP4 experience video, MP3 V12 twin-turbo engine sound):
  - `dealer_map.png`: Milan showroom location map.
  - `engine_sound.mp3`: V12 twin-turbo engine audio effect.
  - `experience_video.mp4`: Rolls-Royce Black Badge cinematic video.
  - `hero_black_badge.png`: Hero header visual.
  - `modal_*.png`: Model showcase visuals (Black Badge, Cullinan, Dawn, Ghost, Phantom, Wraith).
- `README.md`: Project documentation and controls guide.

## ✨ Features & Interactions
1. **Interactive Vehicle Showcase**:
   - Tap on the vehicle showcase cards to explore specifications and details for all 6 Rolls-Royce models:
     - Ghost, Phantom, Wraith, Cullinan, Dawn, and Black Badge.
2. **Audio & Video Integration**:
   - Engine sound playback matching the authentic V12 ignition and rev profile.
   - Built-in video player featuring the Black Badge cinematic experience.
3. **Dealers & Showrooms Drawer**:
   - Slide-up bottom sheet with regional showroom locations and interactive Milan showroom map.
4. **Touch & Motion Feedback**:
   - Fluid touch ripples, responsive gestures, and modal transitions mirroring native iOS/Android mobile web behavior.
5. **Keyboard & Accessibility Shortcuts**:
   - `Escape`: Close active modals, drawers, or video overlay.
   - `Arrow Left` / `Arrow Right`: Navigate between car showcase cards.
